# Field Referencing Implementation Design

**Document Type:** Implementation Design
**Version:** v1.0
**Status:** Implementation In Progress - Phase 1 Complete
**Owner:** Reid Westwood
**Last Updated:** 2025-11-22
**Related Docs:** `thoughts/specs/field_referencing_spec.md`

## Overview

This document provides detailed implementation guidance for the Field Referencing feature, which allows pipeline modules to bind inputs to specific fields of upstream channel values rather than consuming entire models. This enables fine-grained data routing at the pipeline orchestration level without requiring intermediate "unpacker" modules.

## Spec Reference

**Source Spec:** `thoughts/specs/field_referencing_spec.md`

**Key Requirements Addressed:**
1. Parse single-level field references: `channel.field` (Phase 1)
2. Validate field existence at pipeline validation time
3. Validate type compatibility (exact match)
4. Extract fields at runtime in `_resolve_input()`
5. Support `RootModel[T]` for primitives
6. Provide error messages with available fields listed
7. Reject nested field paths in Phase 1
8. Reject private and computed fields

**Out of Scope (Phase 1):**
- Nested field paths (`channel.field.subfield`)
- Computed field extraction
- Field references in EntryPoint/ExitPoint
- Subclass polymorphism (exact type match only)

## Architecture

The field referencing feature extends the existing pipeline infrastructure with minimal invasiveness:

```
┌─────────────────────────────────────────────────────────────────┐
│                        YAML Pipeline Spec                       │
│  "blanket: BlanketConfig fusion_params.blanket_config"          │
└───────────────────────────┬─────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│                  Parser (_parse_inputs)                         │
│  - Split on whitespace: ["BlanketConfig", "fusion_params..."]   │
│  - Detect dot in channel_ref                                    │
│  - Split on first dot: ["fusion_params", "blanket_config"]      │
│  - Validate no nested dots (Phase 1)                            │
└───────────────────────────┬─────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│            PipelineChannelBinding (Data Model)                  │
│  type_name: "BlanketConfig"                                     │
│  channel_name: "fusion_params"                                  │
│  field_path: "blanket_config"     ← NEW                         │
│  source: MODULE                                                 │
└───────────────────────────┬─────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│               Validator (PipelineValidator)                     │
│  1. Build channel type map: {"fusion_params": "FusionParams"}   │
│  2. For each field reference binding:                           │
│     - Resolve parent type from channel_types map                │
│     - Introspect parent_type.model_fields["blanket_config"]     │
│     - Validate field exists, not private, not computed          │
│     - Check type compatibility (exact match)                    │
└───────────────────────────┬─────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│              Executor (_resolve_input)                          │
│  1. Fetch channel: context.get_channel("fusion_params")         │
│  2. Extract field: getattr(fusion_params, "blanket_config")     │
│  3. Check not None (runtime validation for Optional fields)     │
│  4. Return extracted field → module.run(blanket=...)            │
└─────────────────────────────────────────────────────────────────┘
```

**Key Design Decisions:**
- **Parser-level extraction**: Field path extracted during YAML parsing, stored in binding
- **Validator-level type checking**: Channel type map built once, field introspection via Pydantic
- **Executor-level field extraction**: Simple `getattr()` with None check for Optional fields
- **No module awareness**: Modules remain unchanged; they receive extracted fields transparently

### Component 2: YAML Parsing Extension

**File:** `simkit/config/pipeline_schema.py`

**Purpose:** Parse `channel.field` syntax from YAML input strings

**Modified `_parse_inputs()` function (lines 234-262):**

```python
def _parse_inputs(raw_inputs: Dict[str, Any]) -> Dict[str, PipelineChannelBinding]:
    """Parse input bindings from YAML, supporting field references like 'Type channel.field'."""
    bindings: Dict[str, PipelineChannelBinding] = {}
    for field, raw_value in raw_inputs.items():
        if not isinstance(raw_value, str):
            raise ValueError(
                f"Input '{field}' must be a string formatted as '<Type> <channel>' or 'None -> <channel>'"
            )
        value = raw_value.strip()

        # Handle default bindings (unchanged)
        if value.lower().startswith("none"):
            channel_name = _parse_default_channel(value, field)
            binding = PipelineChannelBinding(
                type_name=None,
                channel_name=channel_name,
                source=ChannelSource.DEFAULT,
            )
        else:
            # Split on whitespace: "<Type> <channel_ref>"
            parts = value.split(None, 1)
            if len(parts) != 2:
                raise ValueError(
                    f"Input '{field}' must be formatted as '<Type> <channel>' or '<Type> <channel.field>'"
                )

            type_name, channel_ref = parts

            # NEW: Check for field reference (contains dot)
            if "." in channel_ref:
                # Split on first dot only
                dot_index = channel_ref.index(".")
                channel_name = channel_ref[:dot_index].strip()
                field_path = channel_ref[dot_index + 1:].strip()

                # Phase 1: Reject nested field paths
                if "." in field_path:
                    raise ValueError(
                        f"Input '{field}': Nested field paths not supported in Phase 1 "
                        f"(got '{channel_ref}'). Use single-level fields only (e.g., 'channel.field')."
                    )

                # Validate field_path is not empty
                if not field_path:
                    raise ValueError(
                        f"Input '{field}': Field path cannot be empty (got '{channel_ref}')"
                    )

                binding = PipelineChannelBinding(
                    type_name=type_name.strip(),
                    channel_name=channel_name,
                    field_path=field_path,
                    source=ChannelSource.MODULE,
                )
            else:
                # Standard channel binding (no field reference) - unchanged
                binding = PipelineChannelBinding(
                    type_name=type_name.strip(),
                    channel_name=channel_ref.strip(),
                    source=ChannelSource.MODULE,
                )

        bindings[field] = binding
    return bindings
```

**Dependencies:** `PipelineChannelBinding`, `ChannelSource`

**Integration Points:**
- Called by `_parse_module()` for regular module inputs
- Returns bindings dict used throughout pipeline infrastructure

**Error Cases:**
- Empty field path: `"Type channel."` → `ValueError: Field path cannot be empty`
- Nested paths: `"Type channel.field.subfield"` → `ValueError: Nested field paths not supported in Phase 1`
- Malformed input: `"Type"` (no channel) → `ValueError: must be formatted as '<Type> <channel>'`

**Implementation Notes:**
- Uses `str.index(".")` instead of `str.split(".")` to split only on first dot
- Preserves existing behavior for non-field-reference bindings
- Minimal change to existing parsing logic

### Component 3: Channel Type Registry Builder

**File:** `simkit/core/pipeline_validator.py`

**Purpose:** Build mapping of channel names to type names for field reference validation

**New method in `PipelineValidator` class:**

```python
def _build_channel_type_map(
    self,
    spec: PipelineSpecification,
) -> Dict[str, str]:
    """
    Build a mapping of channel names to their type names.

    Used for field reference validation to determine parent channel types.
    Iterates through all non-exit modules and records their output channel types.

    Args:
        spec: The pipeline specification

    Returns:
        Dict mapping channel_name -> type_name (string)

    Example:
        {
            "fusion_params": "FusionParams",
            "blanket_config": "BlanketConfig",
            "rate_info": "RateInfo"
        }
    """
    channel_types: Dict[str, str] = {}

    for module_key, module_spec in spec.modules.items():
        if module_spec.is_exit:
            continue

        if module_spec.is_entry:
            # Entry module: types come from artifact bindings
            for binding in module_spec.outputs.values():
                if binding.type_name is not None:
                    channel_types[binding.channel_name] = binding.type_name
            continue

        # Regular module: get types from registry descriptor
        descriptor = self._registry.get(module_spec.module_type)

        for field, binding in module_spec.outputs.items():
            # Get expected type from descriptor
            expected_type = descriptor.outputs.get(field)
            if expected_type is not None:
                channel_types[binding.channel_name] = expected_type.__name__

    return channel_types
```

**Modified `validate()` method (lines 47-62):**

```python
def validate(self, spec: PipelineSpecification) -> PipelineGraph:
    self._assert_entry_exit(spec)

    # NEW: Build channel type map for field reference validation
    channel_types = self._build_channel_type_map(spec)

    for module in spec.modules.values():
        if module.is_entry:
            continue
        if module.is_exit:
            self._validate_exit_module(module)
            continue
        descriptor = self._resolve_descriptor(module)
        self._validate_outputs(module, descriptor)
        self._validate_inputs(module, descriptor, channel_types)  # NEW: pass channel_types

    try:
        graph = self._builder.build(spec)
    except PipelineGraphError as exc:
        raise PipelineValidationError(str(exc)) from exc
    return graph
```

**Dependencies:** `PipelineSpecification`, `PipelineModuleRegistry`

**Integration Points:**
- Called once at start of validation
- Result passed to `_validate_inputs()` for field reference validation
- Used to resolve parent channel types without runtime execution

**Key Decisions:**
- Returns string type names (not type objects) for consistency with existing binding `type_name`
- Handles entry modules differently (type from binding vs descriptor)
- Skips exit modules (they don't produce channels)

### Component 4: Field Reference Validator

**File:** `simkit/core/pipeline_validator.py`

**Purpose:** Validate field references using Pydantic introspection

**New method in `PipelineValidator` class:**

```python
def _validate_field_reference(
    self,
    binding: PipelineChannelBinding,
    parent_channel_type_name: str,
    module_key: str,
    field_name: str,
) -> None:
    """
    Validate that a field reference binding is well-formed.

    Performs comprehensive validation:
    1. Parent type exists in schema module
    2. Field exists in parent type
    3. Field is not private (no leading underscore)
    4. Field is not computed (Phase 1 restriction)
    5. Field type matches declared binding type (exact match)

    Args:
        binding: The binding with field_path set
        parent_channel_type_name: The type name of the parent channel
        module_key: Module key for error messages
        field_name: Input field name for error messages

    Raises:
        PipelineValidationError: If any validation check fails

    Example:
        binding = PipelineChannelBinding(
            type_name="BlanketConfig",
            channel_name="fusion_params",
            field_path="blanket_config",
            source=ChannelSource.MODULE
        )
        _validate_field_reference(binding, "FusionParams", "blanket_thermal", "blanket")
    """
    from ..config import schema

    # 1. Resolve parent type
    try:
        parent_type = getattr(schema, parent_channel_type_name)
    except AttributeError:
        raise PipelineValidationError(
            f"Module '{module_key}' input '{field_name}': "
            f"Unknown schema type '{parent_channel_type_name}' for channel '{binding.channel_name}'",
            module=module_key,
        )

    # 2. Check field exists in parent type
    if binding.field_path not in parent_type.model_fields:
        available_fields = ", ".join(sorted(parent_type.model_fields.keys()))
        raise PipelineValidationError(
            f"Module '{module_key}' input '{field_name}': "
            f"Type '{parent_channel_type_name}' has no field '{binding.field_path}'. "
            f"Available fields: {available_fields}",
            module=module_key,
            details={
                "channel": binding.channel_name,
                "parent_type": parent_channel_type_name,
                "field_path": binding.field_path,
                "available_fields": list(parent_type.model_fields.keys()),
            },
        )

    # 3. Check field is not private
    if binding.field_path.startswith("_"):
        raise PipelineValidationError(
            f"Module '{module_key}' input '{field_name}': "
            f"Cannot extract private field '{binding.field_path}' from channel '{binding.channel_name}'",
            module=module_key,
        )

    # 4. Get actual field type
    field_info = parent_type.model_fields[binding.field_path]
    actual_type_annotation = field_info.annotation

    # Unwrap Optional if present
    actual_type = self._unwrap_optional(actual_type_annotation)
    is_optional = actual_type != actual_type_annotation

    # 5. Resolve expected type from binding
    try:
        expected_type = getattr(schema, binding.type_name)
    except AttributeError:
        raise PipelineValidationError(
            f"Module '{module_key}' input '{field_name}': "
            f"Unknown type '{binding.type_name}'",
            module=module_key,
        )

    # 6. Check type compatibility (exact match in Phase 1)
    if actual_type != expected_type:
        raise PipelineValidationError(
            f"Module '{module_key}' input '{field_name}': "
            f"Type mismatch for field '{binding.channel_name}.{binding.field_path}'. "
            f"Expected type '{binding.type_name}', but field has type '{actual_type.__name__}'",
            module=module_key,
            details={
                "expected_type": binding.type_name,
                "actual_type": actual_type.__name__,
                "is_optional": is_optional,
            },
        )

    # 7. Phase 1: Disallow computed fields
    if binding.field_path in parent_type.model_computed_fields:
        raise PipelineValidationError(
            f"Module '{module_key}' input '{field_name}': "
            f"Cannot extract computed field '{binding.field_path}' (not supported in Phase 1)",
            module=module_key,
        )


def _unwrap_optional(self, type_annotation) -> type:
    """
    Unwrap Optional[T] to T. Returns original type if not Optional.

    Handles Python 3.10+ union syntax and typing.Optional:
    - Optional[BlanketConfig] → BlanketConfig
    - BlanketConfig | None → BlanketConfig
    - BlanketConfig → BlanketConfig (unchanged)

    Args:
        type_annotation: Type annotation to unwrap

    Returns:
        The unwrapped type (T) or original if not Optional

    Example:
        >>> from typing import Optional
        >>> _unwrap_optional(Optional[BlanketConfig])
        <class 'BlanketConfig'>
        >>> _unwrap_optional(BlanketConfig)
        <class 'BlanketConfig'>
    """
    import typing

    # Check for Union types (including Optional which is Union[T, None])
    if hasattr(type_annotation, "__origin__") and type_annotation.__origin__ is typing.Union:
        args = type_annotation.__args__
        # Remove None from union args
        non_none_args = [arg for arg in args if arg is not type(None)]
        if len(non_none_args) == 1:
            return non_none_args[0]

    return type_annotation
```

**Modified `_validate_inputs()` method signature and integration (lines 145-186):**

```python
def _validate_inputs(
    self,
    module: PipelineModuleSpec,
    descriptor: ModuleDescriptor,
    channel_types: Dict[str, str],  # NEW parameter
) -> None:
    """
    Validate module inputs against descriptor metadata.

    NEW: Now also validates field references when present.

    Args:
        module: Module spec from YAML
        descriptor: Module metadata from registry
        channel_types: Map of channel_name -> type_name for field reference validation
    """
    expected_inputs = set(descriptor.required_inputs) | set(descriptor.optional_inputs)
    actual_inputs = set(module.inputs.keys())
    missing_required = set(descriptor.required_inputs) - actual_inputs
    if missing_required:
        raise PipelineValidationError(
            "Missing required input bindings",
            module=module.key,
            details={"missing": sorted(missing_required)},
        )
    missing_optional = set(descriptor.optional_inputs) - actual_inputs
    if missing_optional:
        raise PipelineValidationError(
            "Optional inputs must be explicitly bound or defaulted",
            module=module.key,
            details={"missing_optional": sorted(missing_optional)},
        )

    unknown_inputs = actual_inputs - expected_inputs
    if unknown_inputs:
        raise PipelineValidationError(
            "Specification declares inputs not defined by registry",
            module=module.key,
            details={"unknown": sorted(unknown_inputs)},
        )

    for field, binding in module.inputs.items():
        expected_type = (
            descriptor.required_inputs.get(field)
            or descriptor.optional_inputs.get(field)
        )
        if expected_type is None:
            continue  # already handled unknown inputs
        if binding.source is ChannelSource.DEFAULT:
            if field not in descriptor.optional_inputs:
                raise PipelineValidationError(
                    "Default binding supplied for a required input",
                    module=module.key,
                    details={"input": field},
                )
        else:
            # NEW: Validate field references
            if binding.is_field_reference:
                parent_type_name = channel_types.get(binding.channel_name)
                if parent_type_name is None:
                    raise PipelineValidationError(
                        f"Module '{module.key}' input '{field}': "
                        f"Cannot resolve type for channel '{binding.channel_name}' "
                        f"(required for field reference validation)",
                        module=module.key,
                    )
                self._validate_field_reference(
                    binding=binding,
                    parent_channel_type_name=parent_type_name,
                    module_key=module.key,
                    field_name=field,
                )

            # Standard type check (existing logic)
            self._assert_type(binding, expected_type, module.key, field, "input")
```

**Dependencies:**
- `simkit.config.schema` module for type resolution
- `PipelineChannelBinding` for binding introspection
- Pydantic v2 API: `model_fields`, `model_computed_fields`

**Integration Points:**
- Called from `_validate_inputs()` when `binding.is_field_reference` is True
- Uses channel type map from `_build_channel_type_map()`
- Raises `PipelineValidationError` with rich details

**Validation Sequence:**
1. Parent type resolution (fail if unknown)
2. Field existence check (fail with available fields listed)
3. Private field check (fail if starts with `_`)
4. Field type extraction and Optional unwrapping
5. Expected type resolution (fail if unknown)
6. Type compatibility check (fail if mismatch)
7. Computed field check (fail in Phase 1)

### Component 5: Runtime Field Extractor

**File:** `simkit/core/pipeline_executor.py`

**Purpose:** Extract field values at runtime during module execution

**Modified `_resolve_input()` function (lines 290-293):**

```python
def _resolve_input(binding: PipelineChannelBinding, context: PipelineExecutionContext) -> Any:
    """
    Resolve an input binding to its actual value.

    Handles three binding types:
    1. Default bindings (return None for module to fill)
    2. Standard channel bindings (return full channel value)
    3. Field reference bindings (extract field from channel value)  ← NEW

    Args:
        binding: The channel binding to resolve
        context: Execution context with channel storage

    Returns:
        The resolved value (channel value, extracted field, or None)

    Raises:
        PipelineExecutionError: If field extraction fails at runtime
        KeyError: If channel doesn't exist (shouldn't happen with proper validation)

    Example:
        # Standard binding
        binding = PipelineChannelBinding(channel_name="rate_info", source=MODULE)
        _resolve_input(binding, context)  # Returns full RateInfo instance

        # Field reference binding
        binding = PipelineChannelBinding(
            channel_name="fusion_params",
            field_path="blanket_config",
            source=MODULE
        )
        _resolve_input(binding, context)  # Returns BlanketConfig instance (extracted field)
    """
    if binding.source is ChannelSource.DEFAULT:
        return None

    # Fetch channel value
    value = context.get_channel(binding.channel_name)

    # NEW: Extract field if this is a field reference
    if binding.field_path:
        try:
            extracted = getattr(value, binding.field_path)
        except AttributeError:
            # Defensive check (should be caught by validator)
            raise PipelineExecutionError(
                f"Channel '{binding.channel_name}' has no field '{binding.field_path}' "
                f"(type: {type(value).__name__})"
            )

        # Check for None on Optional fields
        if extracted is None:
            raise PipelineExecutionError(
                f"Field '{binding.field_path}' on channel '{binding.channel_name}' is None "
                f"(expected {binding.type_name}). Optional fields must have non-None values at runtime."
            )

        return extracted

    return value
```

**New exception class (add near top of file, around line 25):**

```python
class PipelineExecutionError(Exception):
    """Raised when pipeline execution fails at runtime."""
    pass
```

**Dependencies:**
- `PipelineChannelBinding`
- `PipelineExecutionContext`

**Integration Points:**
- Called from `_execute_module()` for each input binding (line 165)
- Returns value directly to module `run()` method via kwargs dict
- No changes needed to calling code (transparent to executor logic)

**Runtime Behavior:**
1. **Standard bindings**: Return channel value unchanged (existing behavior)
2. **Field reference bindings**:
   - Fetch parent channel value
   - Extract field via `getattr()`
   - Validate field is not None
   - Return extracted field value
3. **Default bindings**: Return None (existing behavior)

**Error Handling:**
- `AttributeError`: Defensive catch for missing fields (validator should prevent this)
- `None` check: Runtime validation for Optional fields (validator allows but runtime enforces)

## Error Handling

### Validation Errors (PipelineValidationError)

**1. Field doesn't exist:**
```
PipelineValidationError: Module 'blanket_thermal' input 'blanket': Type 'FusionParams' has no field 'blanket_cfg'. Available fields: blanket_config, coolant_config, p_fusion, p_thermal_electric, plasma_config

Module: blanket_thermal
Details: {
  "channel": "fusion_params",
  "parent_type": "FusionParams",
  "field_path": "blanket_cfg",
  "available_fields": ["blanket_config", "coolant_config", "p_fusion", ...]
}
```

**2. Type mismatch:**
```
PipelineValidationError: Module 'blanket_thermal' input 'blanket': Type mismatch for field 'fusion_params.blanket_config'. Expected type 'CoolantConfig', but field has type 'BlanketConfig'

Module: blanket_thermal
Details: {
  "expected_type": "CoolantConfig",
  "actual_type": "BlanketConfig",
  "is_optional": false
}
```

**3. Private field:**
```
PipelineValidationError: Module 'blanket_thermal' input 'blanket': Cannot extract private field '_internal_config' from channel 'fusion_params'

Module: blanket_thermal
```

**4. Computed field (Phase 1):**
```
PipelineValidationError: Module 'blanket_thermal' input 'power': Cannot extract computed field 'p_electric' (not supported in Phase 1)

Module: blanket_thermal
```

**5. Unknown parent channel type:**
```
PipelineValidationError: Module 'blanket_thermal' input 'blanket': Cannot resolve type for channel 'fusion_params' (required for field reference validation)

Module: blanket_thermal
```

### Parsing Errors (ValueError)

**1. Nested field path (Phase 1):**
```
ValueError: Input 'temperature': Nested field paths not supported in Phase 1 (got 'fusion_params.blanket.temperature'). Use single-level fields only (e.g., 'channel.field').
```

**2. Empty field path:**
```
ValueError: Input 'blanket': Field path cannot be empty (got 'fusion_params.')
```

### Runtime Errors (PipelineExecutionError)

**1. Optional field is None:**
```
PipelineExecutionError: Field 'optional_blanket' on channel 'fusion_params' is None (expected BlanketConfig). Optional fields must have non-None values at runtime.
```

**2. Field doesn't exist (defensive):**
```
PipelineExecutionError: Channel 'fusion_params' has no field 'blanket_config' (type: FusionParams)
```

### Error Design Principles

1. **Actionable messages**: Include available options when field doesn't exist
2. **Context-rich**: Include module name, field name, channel name in all errors
3. **Structured details**: Use `details` dict for programmatic error handling
4. **Progressive disclosure**: Simple message first, details dict for debugging
5. **User-friendly**: Plain language explanations, not implementation jargon

## Implementation Notes

### Key Technical Decisions

**1. Parser splits on first dot only**
- **Decision**: Use `str.index(".")` and string slicing instead of `str.split(".", 1)`
- **Rationale**: More explicit about "first dot only" behavior for future nested path support
- **Trade-off**: Slightly more verbose than split, but clearer intent

**2. Channel type map built once at validation start**
- **Decision**: Single pass to build map, then passed through validation chain
- **Rationale**: Avoids repeated registry lookups; clear separation of concerns
- **Trade-off**: Requires passing extra parameter through validation methods

**3. Optional field validation passes, runtime fails**
- **Decision**: Validator allows Optional fields, executor checks for None
- **Rationale**: Can't know at validation time if value will be None (data-dependent)
- **Trade-off**: Validation passes but runtime fails (less ideal UX, but technically correct)

**4. Exact type match only (Phase 1)**
- **Decision**: `actual_type != expected_type` (identity check)
- **Rationale**: Simplifies Phase 1, avoids subclass polymorphism complexity
- **Trade-off**: Less flexible than `isinstance()`, but safer and more predictable

**5. Field extraction via getattr**
- **Decision**: Use Python's built-in `getattr()` instead of dict access
- **Rationale**: Works with Pydantic models, cleaner than `__dict__` access
- **Trade-off**: Doesn't support dict-like models (acceptable for StrictBaseModel constraint)

### Gotchas and Edge Cases

**1. MultiOutput field extraction**
- **Issue**: If module produces `MultiOutput`, can we reference fields from its extracted channels?
- **Decision**: Phase 1 restricts field references to channels directly produced by modules
- **Workaround**: Reference the output channel directly, not a field of it

**2. Channel name vs field name collision**
- **Example**: Channel named `config`, field also named `config`
- **Syntax**: `"Config config.config"` is valid (first `config` is channel, second is field)
- **No special handling needed**: Parser splits on dot correctly

**3. Type resolution across packages**
- **Issue**: What if field type is from external package (e.g., `fusion_simkit`)?
- **Limitation**: Phase 1 only supports types in `simkit.config.schema`
- **Future**: Phase 2 could support qualified names like `fusion_simkit.schema.FusionParams`

**4. Field path with spaces**
- **Example**: `"Type channel . field"` (spaces around dot)
- **Handling**: `.strip()` calls remove spaces: `"channel"`, `"field"`
- **Validation**: Empty field check catches `"Type channel. "` → `ValueError`

**5. Case sensitivity**
- **Behavior**: Field names are case-sensitive (Python attribute access)
- **Example**: `blanket_config` ≠ `Blanket_Config`
- **Error message**: Lists available fields for typo correction

### Performance Considerations

**1. Channel type map build cost**
- **Cost**: O(M × F) where M = modules, F = average outputs per module
- **Frequency**: Once per validation (not per module)
- **Impact**: Negligible for typical pipelines (<100 modules)

**2. Pydantic introspection cost**
- **Cost**: `model_fields` dict lookup is O(1)
- **Frequency**: Once per field reference during validation
- **Impact**: Minimal (metadata already cached by Pydantic)

**3. Runtime field extraction cost**
- **Cost**: `getattr()` is O(1) attribute lookup
- **Frequency**: Once per field reference per module execution
- **Impact**: Negligible compared to module execution time

**4. Validation fail-fast**
- **Optimization**: Validation stops on first error (existing behavior)
- **Benefit**: User gets immediate feedback on misconfiguration

### Backward Compatibility

**1. Existing pipelines unchanged**
- Standard bindings (`"Type channel"`) continue to work identically
- No breaking changes to YAML syntax
- No changes to module interfaces

**2. New field added to PipelineChannelBinding**
- `field_path: str | None = None` is optional with default
- Existing code that constructs bindings doesn't need updates
- Pydantic handles serialization/deserialization automatically

**3. Validator signature change**
- `_validate_inputs()` now takes `channel_types` parameter
- Internal method (not public API), safe to change
- No impact on external callers

### Future Enhancements (Phase 2+)

**1. Nested field paths**
- Syntax: `"Type channel.field.subfield"`
- Implementation: Recursive `getattr()` or attribute path traversal
- Validation: Check each level exists and is accessible

**2. Computed field support**
- Remove `model_computed_fields` check in validator
- Test that `getattr()` correctly invokes `@property` methods
- Document that computed fields execute during field extraction

**3. Array indexing**
- Syntax: `"Type channel.field[0]"` or `"Type channel.field.0"`
- Implementation: Custom path parser with index support
- Validation: Check field is list/array type

**4. RootModel auto-wrapping**
- Automatically wrap primitives instead of requiring RootModel in YAML
- Validation detects primitive field type, wraps in RootModel
- Executor unwraps RootModel when passing to module

**5. Type coercion**
- Allow `int` → `float` conversions
- Allow subclass polymorphism (`SubBlanket` → `BlanketConfig`)
- Requires more sophisticated type compatibility checking
